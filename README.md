# Fitness Coaching Website

A responsive landing page for a personal trainer specializing in weight-loss coaching. Built with React and Vite, the website focuses on clear messaging, accessible navigation, and a straightforward consultation booking experience.

## Features

- Responsive layout for desktop, tablet, and mobile devices
- Hero section with a clear call to action
- Coaching services and target audience sections
- Step-by-step coaching process
- Client results and testimonials section
- About the coach section
- FAQ section
- Consultation request form powered by Tally
- Mobile navigation menu
- Scroll progress indicator

## Built With

- React
- Vite
- JavaScript
- CSS
- Tally

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd fitness-coaching-website
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

### Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

## Deployment

The website is deployed with Vercel. Updates pushed to the connected GitHub repository can trigger new deployments.
